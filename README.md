# PatiLife

PatiLife is a modern, local-first pet life and health companion for **Android and iOS**.

The product goal is deliberately broad: combine the pet owner's daily care, health records, reminders, memories and handoff needs in one polished app instead of forcing several separate pet apps.

## Current product direction

The first milestone is not feature sprawl. It is reproducing the approved visual language as a real app shell:

- warm off-white + sage palette
- photo-forward pet cards
- clean typography
- soft premium surfaces
- light + dark mode
- fluid but restrained motion
- platform-natural Android/iOS behavior
- fast bottom-sheet logging

## Core principles

- Android + iOS are developed as one product.
- Core usage remains local-first/offline-first.
- Multiple pets are supported from the data-model level.
- Health and care flows take priority over monetization.
- Ads, if added later, must stay out of critical care and data-entry flows.
- Accessibility, dark mode and platform behavior are part of “done”, not later polish.
